01 متجر PetalVibe للمجوهرات الحرفية

فكرة المشروع: تصميم واجهة متجر إلكتروني متخصصة في عرض المجوهرات المصنوعة يدوياً من الراتنج والزهور المجففة.

ما تم تنفيذه: التركيز على تجربة المستخدم (UI/UX) باستخدام نمط الألوان الداكنة مع لمسات ذهبية فاخرة تبرز جمال المجوهرات، وتضمين نظام عرض تفصيلي لقطع الزينة الحرفية.

HTML5 / CSS3 / Web Design

02 منصة الديكورات والأخشاب الحرفية

فكرة المشروع: منصة لعرض منتجات الديكور المنزلي اليدوية والمصنوعة من الأخشاب ومكرمية الجدار.

ما تم تنفيذه: هيكلة وتطوير شبكة عرض مرنة (Grid Layout) تتيح للزائر تصفح المنتجات بوضوح مع إعطاء مساحة بصرية واسعة تظهر تفاصيل الخامات والملمس الطبيعي.

UI Architecture / Flexbox / Grid

03 استوديو الخدمات الرقمية والتصميم

فكرة المشروع: واجهة رقمية متقدمة مخصصة لتقديم خدمات التصميم الرقمي، الهويات البصرية، وبرمجة المواقع المصغرة.

ما تم تنفيذه: تصميم بيئة عمل تفاعلية تعكس طابع الوكالات التقنية الحديثة، مع تنظيم الأقسام لعرض الخدمات الاحترافية وسهولة تواصل العميل.

Digital Agency UI / Modern CSS

04 متجر الجلود والمصنوعات الطبيعية

فكرة المشروع: متجر تجارة إلكترونية مصمم لعرض المحافظ والأحزمة والمنتجات الجلدية المصنوعة يدوياً.

ما تم تنفيذه: دمج صور ماكرو دقيقة توضح تفاصيل الحياكة اليدوية الدقيقة (Saddle Stitch)، مع تصميم بطاقات عرض منتجات احترافية ومباشرة.

E-Commerce UI / Macro Visuals

05 معرض أعمال المصممين والمطورين

فكرة المشروع: منصة شخصية لعرض المشاريع البرمجية والتصميمية الفنية للمطورين والمبدعين.

ما تم تنفيذه: بناء تصميم شبكي متجاوب (Responsive Grid) يضمن ظهور المشاريع بوضوح تام على مختلف الشاشات (حواسيب، أجهزة لوحية، وهواتف).

Responsive Design / Portfolio Grid

06 معرض الفنون التشكيلية واللوحات

فكرة المشروع: موقع فني مظلم وهادئ مخصص لعرض اللوحات الفنية والرسومات الرقمية والتكيلية.

ما تم تنفيذه: استخدام خلفيات داكنة عميقة (Obsidian/Dark Mode) لكي تبرز الألوان واللوحات الفنية بشكل ساطع وجذاب يخطف انتباه الزائر فور دخول الموقع.

Dark Mode Aesthetics / Art Gallery
